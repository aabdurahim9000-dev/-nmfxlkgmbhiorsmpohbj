# Джарвис для телефона

Голосовой помощник в виде приложения (PWA): расписание на день с напоминаниями, таймеры, заметки,
погода, ИИ (по желанию), игры и приколы. Работает на Android и iPhone, ставится иконкой на экран.

## Как выложить через GitHub Pages

1. Создай на github.com новый репозиторий (например `jarvis`), публичный.
2. Загрузи в него все файлы из этой папки (кнопка «Add file → Upload files»), включая файл `.nojekyll`.
3. Открой Settings → Pages → Source: «Deploy from a branch», ветка `main`, папка `/ (root)` → Save.
4. Через минуту-две приложение откроется по адресу `https://ТВОЙ_ЛОГИН.github.io/jarvis/`.

## Как поставить на телефон

- Android (Chrome): открой адрес → меню ⋮ → «Установить приложение» (или кнопка в Настройках).
- iPhone (Safari): открой адрес → «Поделиться» → «На экран Домой».

## Что важно знать

- Голос: нажми на микрофон и говори команду. Режим «Всегда слушать» (слово «Джарвис») лучше всего работает
  в Chrome на Android при включённом экране. Распознаванию речи нужен интернет.
- Напоминания по расписанию срабатывают, пока приложение открыто или в фоне. Если телефон выгрузил его
  из памяти, напомнит при следующем открытии.
- Все данные (расписание, заметки, ключи ИИ) лежат только в браузере на телефоне.
- Телефон не даёт сайтам управлять громкостью, закрывать приложения и т. п., поэтому часть команд
  из ПК-версии здесь заменена на открытие сайтов и приложений по ссылке (Telegram, WhatsApp, Spotify…).
